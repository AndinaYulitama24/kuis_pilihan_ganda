## Informasi Aplikasi
* **Nama Aplikasi:** Kuis 
* **Deskripsi Singkat:** Aplikasi kuis pilihan ganda interaktif yang memungkinkan pengguna menguji pengetahuan berdasarkan kategori tertentu, dengan batas waktu, penjelasan jawaban, dan riwayat skor.
* **Fitur-fitur Utama:**
  1. Input nama pengguna dan pemilihan 3 kategori (Umum, Teknologi, Indonesia).
  2. Timer 15 detik untuk setiap soal.
  3. Penjelasan jawaban (muncul jika pengguna menjawab salah).
  4. Penyimpanan riwayat nilai dan detail kesalahan menggunakan *Shared Preferences* (Local Storage).
  5. **Dual-Theme:** Mendukung mode terang (Light Mode) dan gelap (Dark Mode).
  6. **Responsive Design:** Tampilan UI yang adaptif (tidak overflow) saat dijalankan di HP (portrait/landscape), Tablet, maupun Web.
